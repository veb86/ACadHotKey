# Релиз без инсталлятора (issue #4)

Основание: https://github.com/veb86/ACadHotKey/issues/4. Прочитаны описание, все комментарии,
список sub-issues, обсуждение, inline-комментарии и reviews PR #5: дополнительных требований нет.
Изучены последний релиз v1.0.8, workflow и инструкция ручной установки TeplovPrint-AutoCAD.

| Требование | Реализация | Проверка |
|---|---|---|
| Готовый архив в выпусках | `ACadHotKey-manual-install-v<версия>.zip`, SHA256, workflow публикации | Сборка ZIP, проверка контрольной суммы; CI для текущего SHA |
| Ручная установка без инсталлятора и администратора | `ACadHotKey.bundle` и `INSTALL.md` в корне ZIP; копирование в `%APPDATA%` | Проверка состава ZIP и копирования в тестовый профиль пользователя |
| Только профиль пользователя | `%APPDATA%\Autodesk\ApplicationPlugins\ACadHotKey.bundle` | Инструкция установки, обновления, удаления; отсутствие установщиков в ZIP |
| AutoCAD 2020–2024, автозагрузка | Две сборки SDK 23.1/net47 и 24.0/net48; `PackageContents.xml` | Выбор ровно одного компонента для каждой версии, startup-флаг, зависимости и XML |
| Подготовка следующего релиза | Версия проекта и манифеста 0.3.0, совпадение с тегом | Отказ при несовпадающих версиях/теге |
| Завершение PR | Атомарные коммиты, актуальная main, обновлённое описание с `Fixes`, ready | Diff, чистый Git, проверки GitHub |

Порядок работы: подготовить упаковку и инструкции; добавить регрессионные проверки и workflow;
выполнить сфокусированные локальные проверки; проверить CI, diff и описание PR.

Принято: архив содержит папку пакета непосредственно в корне, чтобы её можно было скопировать
в `ApplicationPlugins` целиком. Отдельные установщики, запись в системные каталоги, реестр,
поддержка AutoCAD 2025+ не требуются. Релиз публикуется после слияния/тега; PR не сливается агентом.
Проверки настоящего интерфейса AutoCAD из issue #1 остаются описаны в `host-verification.md`;
упаковочные проверки подтверждают структуру автозагрузки, а не выполнение команд внутри AutoCAD.

## Результаты

* Локально: две сборки Release (SDK 23.1/net47 и SDK 24.0/net48), 0 предупреждений / 0 ошибок.
* `release_package.py`: создан ZIP 0.3.0 из восьми файлов, проверены CRC и SHA256,
  распаковка и копирование полного пакета в тестовый `%APPDATA%` (путь содержит пробелы).
* `test_release_package.py`: 10 тестов прошли, включая отрицательные сценарии для зависимостей,
  посторонних файлов, манифеста, XML, версии, тега, контрольной суммы и структуры ZIP.
* `test-package.sh`: обе существующие регрессии прошли. Старая папка `Contents/old` перед сборкой
  была намеренно добавлена; после сборки её нет в пакете и ZIP.
* `actionlint`: workflow принят без замечаний. `bash -n` и `git diff --check` успешны.
* [CI на Linux и Windows](https://github.com/konard/veb86-ACadHotKey/actions/runs/44072107716)
  для commit `4eb0cfb`: на каждой ОС 115 тестов логики, 10 тестов выпуска и проверки пакета прошли.
  Задание публикации корректно пропущено для рабочей ветки.
* Артефакт `release-archives` скачан из CI: повторно проверены ZIP, SHA256, состав и копирование
  в тестовый профиль. Сборки выполняются последовательно, без постоянного сервера компилятора.
* Аудит `gh pr diff 5`: логика горячих клавиш и существующие команды сохранены;
  основная ветка `086134f` входит в историю PR. Текущее состояние проверок отражено в описании PR.

Локальные журналы: `experiments/logs/` (исключены из Git).
